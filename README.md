# MO_Shooter

Lyra 클라이언트에 붙이는 **서버 권위 MO 슈팅 서버**입니다. 판정을 직접 짠 서버가 맡아 한 판을 끝까지 돌리고, 더미로 여러 방을 돌려 한계를 재고, FPS 서버 최적화와 서버 권위 컨텐츠를 숫자로 보이는 프로젝트입니다.

네트워크 토대는 [ServerCore](https://github.com/cocoz93/ServerCore) 를 그대로 씁니다. 이 리포에는 **게임 층과 공용 계산**만 있습니다.

```
Shared/      공용 계산 — 이동·충돌·사격 판정·와이어 형식 · 뽑은 맵 충돌 (서버와 클라가 같은 코드를 쓴다)
Server/      매치 서버 게임 층 — 방 여러 개, 방마다 고정 틱
BotClient/   콘솔 봇·더미 클라이언트 — 화면 없이 붙어서 걷고 쏜다
Tools/       파일럿 서버 등
ServerCore/  서브모듈 (수정은 그 리포에서)
LockFree/    서브모듈 (ServerCore 가 참조)
```

## 왜 클라이언트가 둘인가

사람이 하는 클라이언트는 Lyra + 다리 플러그인 `MOBridge` 입니다. 화면·애니·HUD는 Lyra 그대로 두고, 판정만 막은 뒤 서버 결과를 넣습니다.
콘솔 클라이언트는 그림 없이 같은 프로토콜로 붙습니다. 판정 검증과 부하 측정에 씁니다.

## 빌드

CMake. `ServerCore` 와 `LockFree` 는 서브모듈이라 클론할 때 같이 받아야 합니다.

```
git clone --recursive <이 리포>
```

## 상태

1단계(서버가 쓸 판정 계산) 진행 중입니다.
